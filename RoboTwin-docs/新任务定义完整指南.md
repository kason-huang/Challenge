# RoboTwin 新任务定义完整指南

## 概述

本文档详细说明如何在 RoboTwin 框架中定义一个新任务。RoboTwin 采用**三层架构**设计，使得任务定义具有高度的可扩展性和灵活性。

```
┌─────────────────────────────────────────────────────────────┐
│ 第1层：Python 任务类 (Task Definition)                │
│   envs/my_new_task.py                                │
│   ├─ setup_demo()      场景初始化                    │
│   ├─ load_actors()     加载任务物体                   │
│   ├─ play_once()       专家动作序列 + info字典返回      │
│   └─ check_success()   成功条件判断                   │
└─────────────────────────────────────────────────────────────┘
                    │ 返回 info 字典
                    ▼
┌─────────────────────────────────────────────────────────────┐
│ 第2层：场景信息 (Scene Info)                          │
│   {task_name}/{task_config}/scene_info.json            │
│   episode_0: {"{A}": "001_bottle/base2", ...}      │
│   episode_1: {"{A}": "001_bottle/base3", ...}      │
└─────────────────────────────────────────────────────────────┘
                    │ 用于指令生成和评测复现
                    ▼
┌─────────────────────────────────────────────────────────────┐
│ 第3层：指令系统 (Instruction System)                   │
│   description/task_instruction/my_new_task.json          │
│   "seen": ["Pick {A} and place it on table", ...]    │
│   "unseen": ["Stack the {A} on the table", ...]     │
└─────────────────────────────────────────────────────────────┘
```

## 一、任务定义的核心组件

### 1.1 Python 任务类结构

每个任务都是 `Base_Task` 的子类，必须实现以下方法：

```python
from ._base_task import Base_Task
from .utils import *
import sapien
import numpy as np

class my_new_task(Base_Task):

    def setup_demo(self, **kwargs):
        """初始化任务环境，设置随机种子、渲染等"""
        super()._init_task_env_(**kwargs)
        # 可选：自定义初始化逻辑

    def load_actors(self):
        """加载任务所需的物体"""
        # 1. 创建物体（使用 create_actor 或 create_box）
        # 2. 设置物体属性（质量、碰撞等）
        # 3. 定义禁止区域（add_prohibit_area）
        # 4. 定义目标位置和姿态

    def play_once(self):
        """定义专家动作序列"""
        # 1. 执行一系列动作（grasp_actor, place_actor, move_by_displacement 等）
        # 2. 记录使用的机械臂和物体信息
        # 3. 返回 info 字典（关键！）
        self.info["info"] = {
            "{A}": "物体类型/模型ID",
            "{B}": "物体类型/模型ID",
            "{a}": "使用的机械臂",
            "{b}": "使用的机械臂",
        }
        return self.info

    def check_success(self):
        """定义任务成功条件"""
        # 检查物体位置、姿态、接触状态等
        # 返回布尔值
        return condition1 and condition2 and condition3
```

### 1.2 Base_Task 提供的核心方法

`Base_Task` 提供了丰富的工具方法供子类使用：

#### 场景初始化
- `_init_task_env_(**kwargs)`: 初始化仿真引擎、相机、物理参数
- `setup_scene()`: 创建场景（桌子、墙、光照等）
- `get_cluttered_table()`: 添加干扰物体（杂乱场景）

#### 物体操作
- `create_actor(scene, pose, modelname, model_id, ...)`: 从 RoboTwin-OD 加载物体
- `create_box(scene, pose, half_size, color, ...)`: 创建简单几何体
- `add_prohibit_area(actor, padding)`: 定义禁止区域（干扰物体不会放置于此）

#### 抓取与放置
- `grasp_actor(actor, arm_tag, contact_point_id, pre_grasp_dis, ...)`: 抓取物体
- `place_actor(actor, target_pose, arm_tag, functional_point_id, ...)`: 放置物体
- `move_bowl(self, actor, target_pose)`: 移动物体（自定义辅助函数）

#### 运动控制
- `move(*actions)`: 并行执行多个动作
- `move_to_pose(arm_tag, target_pose)`: 移动机械臂到位姿
- `move_by_displacement(arm_tag, x, y, z)`: 相对位移移动
- `back_to_origin(arm_tag)`: 返回初始位置

#### 状态检查
- `check_success()`: 子类实现的成功条件检查
- `check_stable()`: 场景稳定性检查
- `is_left_gripper_open()`: 检查左夹爪状态
- `is_right_gripper_open()`: 检查右夹爪状态
- `check_actors_contact(actor1_name, actor2_name)`: 检查物体接触

## 二、完整任务定义流程

### 2.1 步骤 1：创建任务文件

在 `RoboTwin/envs/` 目录下创建新文件 `my_new_task.py`：

```python
from ._base_task import Base_Task
from .utils import *
import sapien
import numpy as np
import math

class my_new_task(Base_Task):

    def setup_demo(self, **kwargs):
        """
        初始化任务环境
        """
        super()._init_task_env_(**kwargs)

    def load_actors(self):
        """
        加载任务所需的物体
        """
        # 示例：加载一个瓶子和一个杯子
        # 1. 生成随机位置
        bottle_pose = rand_pose(
            xlim=[-0.3, 0.3],
            ylim=[-0.15, 0.15],
            zlim=[0.74],  # 桌子高度
            qpos=[0.5, 0.5, 0.5, 0.5],  # 四元数（朝上）
            ylim_prop=True,
            rotate_rand=True,
            rotate_lim=[0, 0, 0.5 * math.pi],  # z轴旋转±90°
        )

        # 2. 创建瓶子
        self.bottle = create_actor(
            scene=self,
            pose=bottle_pose,
            modelname="001_bottle",
            model_id=2,  # 瓶子的第2个模型
            convex=True,  # 凸包优化碰撞检测
        )

        # 3. 生成杯子位置（确保与瓶子不重叠）
        cup_pose = rand_pose(...)
        # ... 检查重叠逻辑 ...

        # 4. 创建杯子
        self.cup = create_actor(
            scene=self,
            pose=cup_pose,
            modelname="003_cup",
            model_id=1,
            convex=True,
        )

        # 5. 设置禁止区域（防止干扰物体放置在此）
        self.add_prohibit_area(self.bottle, padding=0.07)
        self.add_prohibit_area(self.cup, padding=0.07)

        # 6. 定义目标位置
        self.target_pose = [-0.1, -0.15, 0.76]  # [x, y, z]

    def play_once(self):
        """
        定义专家动作序列
        """
        # 示例：将瓶子移动到目标位置，然后把杯子放在瓶子上

        # 步骤1：移动瓶子
        arm_tag1 = ArmTag("left" if self.bottle.get_pose().p[0] < 0 else "right")
        self.move(self.grasp_actor(self.bottle, arm_tag=arm_tag1, pre_grasp_dis=0.1))
        self.move(self.move_by_displacement(arm_tag=arm_tag1, z=0.1))

        self.move(self.place_actor(
            actor=self.bottle,
            target_pose=self.target_pose + [0, 0, 0, 0.707, 0.707, 0],
            arm_tag=arm_tag1,
            functional_point_id=0,
            pre_dis=0.09,
            dis=0,
            constrain="align",
        ))

        # 步骤2：移动杯子到瓶子上方
        arm_tag2 = arm_tag1  # 使用同一只手臂
        self.move(self.grasp_actor(self.cup, arm_tag=arm_tag2, pre_grasp_dis=0.1))
        self.move(self.move_by_displacement(arm_tag=arm_tag2, z=0.1))

        bottle_top_pose = self.bottle.get_pose().p + [0, 0, 0.1]
        self.move(self.place_actor(
            actor=self.cup,
            target_pose=bottle_top_pose.tolist() + [0, 0.707, 0.707, 0],
            arm_tag=arm_tag2,
            functional_point_id=0,
            pre_dis=0.09,
            dis=0,
            constrain="align",
        ))

        # 步骤3：打开夹爪（释放物体）
        self.together_open_gripper(save_freq=None)

        # 步骤4：返回 info 字档（关键！）
        self.info["info"] = {
            "{A}": "001_bottle/base2",  # 瓶子类型
            "{B}": "003_cup/base1",     # 杯子类型
            "{a}": str(arm_tag1),        # 哪个臂抓了瓶子
            "{b}": str(arm_tag2),        # 哪个臂抓了杯子
        }
        return self.info

    def check_success(self):
        """
        定义任务成功条件
        """
        bottle_pose = self.bottle.get_pose().p
        cup_pose = self.cup.get_pose().p

        # 条件1：瓶子在目标位置（±2cm 容差）
        target_dist = np.linalg.norm(bottle_pose[:2] - np.array([-0.1, -0.15]))
        condition1 = target_dist < 0.02

        # 条件2：杯子在瓶子上方（±2cm xy, ±2cm z）
        xy_dist = np.linalg.norm(cup_pose[:2] - bottle_pose[:2])
        z_dist = abs(cup_pose[2] - (bottle_pose[2] + 0.1))
        condition2 = xy_dist < 0.02 and z_dist < 0.02

        # 条件3：双爪都打开（释放物体）
        condition3 = self.is_left_gripper_open() and self.is_right_gripper_open()

        return condition1 and condition2 and condition3
```

### 2.2 步骤 2：配置任务参数

#### 添加步数限制

在 `task_config/_eval_step_limit.yml` 中添加：

```yaml
my_new_task: 600  # 根据任务复杂度调整
```

**步数限制参考**：
- 简单任务（单物体抓取）：400-500 步
- 中等任务（双物体堆叠）：800-900 步
- 复杂任务（多物体排序）：1200-1500 步

#### 域随机化配置（可选）

根据任务需求修改 `task_config/demo_randomized.yml` 或 `task_config/demo_clean.yml`：

```yaml
# demo_randomized.yml (Hard 模式)
domain_randomization:
  random_background: true        # 随机背景纹理（11,000+ 张）
  cluttered_table: true        # 添加10个干扰物体
  clean_background_rate: 0.02   # 2%概率使用清洁背景
  random_head_camera_dis: 0
  random_table_height: 0.03     # 桌高±3cm
  random_light: true            # 随机光照颜色、强度、位置
  crazy_random_light_rate: 0.02 # 2%极端光照
```

### 2.3 步骤 3：创建指令模板

在 `description/task_instruction/my_new_task.json` 中创建：

```json
{
  "full_description": "pick up a bottle and place a cup on top of it",
  "schema": "{A} denotes the bottle, {B} denotes the cup",
  "preference": "num of words should not exceed 15. Degree of detail avg 5",

  "seen": [
    "Pick up {A} and place {B} on top of it",
    "Lift {A}, then stack {B} on top of the {A}",
    "Grab the {A} and position it, then set {B} over it",
    "Move the {A} to table, place {B} on top",
    "Use {a} arm to pick up {A}, then stack {B} using {b} arm",
    "With {a} arm, lift {A}, and place {B} on top",
    "Grab the {A}, position on surface, and put {B} over it",
    "Take the {A}, set it down, then place {B} on top",
    ...
  ],

  "unseen": [
    "Stack {B} on top of {A}",
    "Place {B} over the {A}",
    "Pick up {A} and put {B} on it",
    ...
  ]
}
```

**关键设计原则**：
- `{A}`, `{B}`, `{C}`...: 大写字母占位符，表示物体
- `{a}`, `{b}`, `{c}`...: 小写字母占位符，表示机械臂
- `seen` 数组：训练集指令（50条左右）
- `unseen` 数组：评测集指令（10条左右）

### 2.4 步骤 4：添加物体描述（如果使用新物体）

如果任务使用了 RoboTwin-OD 中没有的新物体，需要在 `description/objects_description/` 中添加描述文件：

```json
{
  "seen": [
    "A clear glass bottle",
    "A plastic water bottle",
    "A medium-sized beverage bottle",
    "A transparent bottle with narrow neck",
    ...
  ],
  "unseen": [
    "A green bottle",
    "A dark plastic bottle",
    ...
  ]
}
```

**每个物体需要 15 个描述**：
- `seen`: 12 条训练用描述
- `unseen`: 3 条评测用描述

## 三、关键模式与最佳实践

### 3.1 物体位置生成模式

**避免重叠检查**：
```python
def load_actors(self):
    object_poses = []

    for i in range(3):
        # 生成初始位置
        pose = rand_pose(...)

        # 检查是否与已有物体重叠
        def check_pose_overlap(pose):
            for j in range(len(object_poses)):
                if np.sum(pow(pose.p[:2] - object_poses[j].p[:2], 2)) < 0.0169:
                    return False  # 距离 < 0.13cm 认为重叠
            return True

        # 如果重叠，重新生成
        while not check_pose_overlap(pose):
            pose = rand_pose(...)

        object_poses.append(pose)
```

**避开特定区域**：
```python
# 避开目标放置区域
while np.sum(pow(pose.p[:2] - np.array([0, -0.1]), 2)) < 0.01:
    pose = rand_pose(...)
```

### 3.2 机械臂选择策略

**根据物体位置自动选择机械臂**：
```python
def play_once(self):
    # x < 0 使用左臂，x >= 0 使用右臂
    arm_tag = ArmTag("left" if actor.get_pose().p[0] < 0 else "right")
```

**保持机械臂使用一致性**：
```python
def play_once(self):
    self.last_arm = None  # 记录上次使用的臂

    for actor, target in zip(actors, targets):
        arm_tag = ArmTag("left" if actor.get_pose().p[0] < 0 else "right")

        if self.last_arm is not None and self.last_arm != arm_tag:
            # 需要切换手臂，先移动非活动臂到原点
            self.move(
                self.grasp_actor(actor, arm_tag=arm_tag, ...),
                self.back_to_origin(arm_tag=self.last_arm),
            )
        else:
            self.move(self.grasp_actor(actor, arm_tag=arm_tag, ...))

        self.last_arm = arm_tag
```

### 3.3 成功条件判断模式

**空间位置检查**：
```python
def check_success(self):
    actor_pose = self.actor.get_pose().p
    target_pose = self.target_pose  # [x, y, z]

    # 容差：xy 方向 ±2cm，z 方向 ±2cm
    eps = np.array([0.02, 0.02, 0.02])

    return np.all(abs(actor_pose - target_pose) < eps)
```

**接触状态检查**：
```python
def check_success(self):
    # 检查两个物体是否接触
    return self.check_actors_contact(
        self.actor1.get_name(),
        self.actor2.get_name()
    )
```

**复合条件检查**：
```python
def check_success(self):
    # 条件1：空间位置正确
    condition1 = self._check_position()

    # 条件2：姿态正确（四元数距离）
    quat_dist = cal_quat_dis(actor.get_pose().q, target_quat)
    condition2 = quat_dist * 180 < 3.0  # 旋转角度 < 3°

    # 条件3：夹爪打开
    condition3 = self.is_left_gripper_open() and self.is_right_gripper_open()

    return condition1 and condition2 and condition3
```

### 3.4 动作序列设计模式

**简单抓取-放置**：
```python
self.move(
    self.grasp_actor(actor, arm_tag=arm_tag, pre_grasp_dis=0.1)
)
self.move(self.move_by_displacement(arm_tag, z=0.1))  # 提起物体
self.move(self.place_actor(actor, target_pose, arm_tag=arm_tag, ...))
```

**堆叠序列**：
```python
# 1. 移动底部物体
arm_tag1 = self.move_actor(self.object1, target1)

# 2. 移动顶部物体到底部物体上方
arm_tag2 = self.move_actor(self.object2, self.object1.get_pose().p + [0, 0, 0.05])

# 3. 避免碰撞：再次提起物体
self.move(self.move_by_displacement(arm_tag2, z=0.09))

# 4. 放置物体
self.move(self.place_actor(self.object2, target2, arm_tag=arm_tag2, ...))
```

**双臂协作**：
```python
# 同时抓取两个物体
self.move(
    self.grasp_actor(actor1, arm_tag=ArmTag("left"), ...),
    self.grasp_actor(actor2, arm_tag=ArmTag("right"), ...),
)
```

## 四、任务类型分类与示例

### 4.1 按复杂度分类

| 复杂度 | 特征 | 示例任务 | 步数限制 |
|---------|------|-----------|---------|
| **简单** | 单物体、单次抓取 | `place_empty_cup`, `click_alarmclock` | 400-500 |
| **中等** | 双物体、简单堆叠 | `stack_bowls_two`, `place_bread_skillet` | 800-900 |
| **复杂** | 多物体、排序、多步堆叠 | `stack_bowls_three`, `blocks_ranking_rgb`, `put_bottles_dustbin` | 1200-1700 |

### 4.2 按操作类型分类

#### 抓取-放置任务
**特点**：单次抓取，放置到目标位置

**示例**：
```python
class place_empty_cup(Base_Task):
    def play_once(self):
        arm_tag = ArmTag("left" if self.cup.get_pose().p[0] < 0 else "right")

        self.move(self.grasp_actor(self.cup, arm_tag=arm_tag))
        self.move(self.move_by_displacement(arm_tag, z=0.1))
        self.move(self.place_actor(self.cup, self.target_pose, arm_tag=arm_tag))

        self.info["info"] = {
            "{A}": "042_cup/base3",
            "{a}": str(arm_tag),
        }
        return self.info
```

#### 堆叠任务
**特点**：多个物体按特定顺序堆叠

**示例**：
```python
class stack_bowls_two(Base_Task):
    def play_once(self):
        # 移动第一个碗到底部
        arm_tag1 = self.move_bowl(self.bowl1, self.bowl1_target_pose)

        # 移动第二个碗到第一个碗上方
        arm_tag2 = self.move_bowl(self.bowl2, self.bowl1.get_pose().p + [0, 0, 0.05])

        # 再次提起避免碰撞
        self.move(self.move_by_displacement(arm_tag2, z=0.09))

        # 放置第二个碗
        self.move(self.place_actor(self.bowl2, self.bowl1_target_pose, arm_tag=arm_tag2, ...))

        self.info["info"] = {
            "{A}": "002_bowl/base3",
            "{B}": "002_bowl/base3",
            "{a}": str(arm_tag1),
            "{b}": str(arm_tag2),
        }
        return self.info
```

#### 排序任务
**特点**：多个物体按特定属性（颜色、大小、RGB）排序

**示例**：
```python
class blocks_ranking_rgb(Base_Task):
    def load_actors(self):
        # 创建红、绿、蓝三个方块
        self.block1 = create_box(self, ..., color=(1, 0, 0))  # 红
        self.block2 = create_box(self, ..., color=(0, 1, 0))  # 绿
        self.block3 = create_box(self, ..., color=(0, 0, 1))  # 蓝

        # 定义目标位置（从左到右：红、绿、蓝）
        self.block1_target_pose = [-0.1, -0.1, 0.74] + [0, 1, 0, 0]
        self.block2_target_pose = [0, -0.1, 0.74] + [0, 1, 0, 0]
        self.block3_target_pose = [0.1, -0.1, 0.74] + [0, 1, 0, 0]

    def play_once(self):
        # 按顺序移动方块
        arm_tag1 = self.pick_and_place_block(self.block1, self.block1_target_pose)
        arm_tag2 = self.pick_and_place_block(self.block2, self.block2_target_pose)
        arm_tag3 = self.pick_and_place_block(self.block3, self.block3_target_pose)

        self.info["info"] = {
            "{A}": "red block",
            "{B}": "green block",
            "{C}": "blue block",
            "{a}": arm_tag1,
            "{b}": arm_tag2,
            "{c}": arm_tag3,
        }
        return self.info
```

#### 双臂协作任务
**特点**：两臂同时操作不同物体

**示例**：
```python
class place_bread_skillet(Base_Task):
    def play_once(self):
        arm_tag = ArmTag("right" if self.skillet.get_pose().p[0] > 0 else "left")

        # 同时抓取煎锅和面包
        self.move(
            self.grasp_actor(self.skillet, arm_tag=arm_tag, ...),
            self.grasp_actor(self.bread, arm_tag=arm_tag.opposite, ...),
        )

        # 同时提起
        self.move(
            self.move_by_displacement(arm_tag, z=0.1),
            self.move_by_displacement(arm_tag.opposite, z=0.1),
        )

        # 放置煎锅
        self.move(self.move_to_pose(arm_tag=arm_tag, target_pose=skillet_target))

        # 放置面包到煎锅上
        self.move(self.place_actor(self.bread, self.skillet.get_functional_point(0), ...))

        self.info["info"] = {
            "{A}": "106_skillet/base1",
            "{B}": "075_bread/base2",
            "{a}": str(arm_tag),
        }
        return self.info
```

## 五、高级技巧

### 5.1 功能点（Functional Point）使用

RoboTwin 每个物体都标注了功能点，用于精确定位：

```python
# 获取物体的功能点
functional_point = actor.get_functional_point(0)  # 返回 Pose

# 使用功能点作为目标位置
self.move(self.place_actor(
    actor=self.cup,
    target_pose=functional_point,  # 直接使用功能点
    arm_tag=arm_tag,
    ...
))
```

**功能点用途**：
- `functional_point_id=0`: 通常物体的中心或底部
- 确保物体与其他物体精确对齐
- 避免手动计算目标位置

### 5.2 动态目标位置

根据场景动态计算目标位置：

```python
def play_once(self):
    # 移动第一个物体到固定位置
    self.move_actor(self.object1, fixed_target)

    # 第二个物体的目标位置基于第一个物体的当前位置
    target2 = self.object1.get_pose().p + [0, 0, 0.1]

    # 移动第二个物体
    self.move_actor(self.object2, target2)
```

### 5.3 约束类型选择

`place_actor` 支持三种约束模式：

```python
# 1. align: 对齐到目标位置（最常用）
self.move(self.place_actor(..., constrain="align"))

# 2. free: 自由放置（不约束姿态）
self.move(self.place_actor(..., constrain="free"))

# 3. 指定四元数: 精确控制姿态
self.move(self.place_actor(
    ...,
    target_pose=[x, y, z, qx, qy, qz, qw]
))
```

### 5.4 质量调整

调整物体质量以改变物理行为：

```python
def load_actors(self):
    self.light_object = create_actor(...)
    self.light_object.set_mass(0.001)  # 超轻物体

    self.heavy_object = create_actor(...)
    self.heavy_object.set_mass(0.01)  # 较重物体
```

**质量设置参考**：
- 纸、卡片、轻质餐具：0.001 kg
- 碗、杯子、锤子：0.01 kg
- 锅、重物：0.05 kg

### 5.5 随机化技巧

**物体模型随机选择**：
```python
def load_actors(self):
    model_id_list = [0, 1, 2, 3]
    selected_id = np.random.choice(model_id_list)

    self.object = create_actor(
        scene=self,
        pose=pose,
        modelname="002_bowl",
        model_id=selected_id,  # 随机选择碗的模型
    )
```

**物体位置随机化**：
```python
# 在范围内随机生成位置
pose = rand_pose(
    xlim=[-0.3, 0.3],        # x: -0.3 ~ 0.3 m
    ylim=[-0.15, 0.15],      # y: -0.15 ~ 0.15 m
    zlim=[0.74],             # z: 固定在桌面上
    qpos=[0.5, 0.5, 0.5, 0.5],  # 初始四元数（朝上）
    rotate_rand=True,          # 随机旋转
    rotate_lim=[0, 0, 0.5*math.pi],  # z轴旋转±90°
)
```

## 七、常见问题与调试

### 7.1 物体重叠问题

**症状**：物体初始化后掉落或穿模

**解决方案**：
```python
# 添加距离检查
def check_no_overlap(pose, existing_poses, min_dist=0.13):
    for existing_pose in existing_poses:
        if np.sum(pow(pose.p[:2] - existing_pose.p[:2], 2)) < min_dist**2:
            return False
    return True

while not check_no_overlap(pose, object_poses):
    pose = rand_pose(...)
```

### 7.2 专家轨迹失败

**症状**：`plan_success = False`，无法规划路径

**解决方案**：
1. 检查目标位置是否在工作空间内
2. 增加 `pre_dis`（预抓取距离）
3. 调整 `functional_point_id`（选择不同的抓取点）
4. 检查物体姿态是否合理（四元数）

```python
# 尝试多个抓取点
for contact_point_id in [0, 1, 2]:
    self.move(self.grasp_actor(actor, arm_tag=arm_tag, contact_point_id=contact_point_id))
    if self.plan_success:
        break
```

### 7.3 成功条件过于严格

**症状**：成功率 < 10%

**解决方案**：
1. 增加容差（eps）
2. 检查是否有隐式条件（如夹爪状态）
3. 使用调试模式观察失败原因

```python
def check_success(self):
    # 宽松的条件
    eps = 0.05  # 5cm 容差

    # 调试输出
    print(f"Bottle pose: {self.bottle.get_pose().p}")
    print(f"Target pose: {self.target_pose}")
    print(f"Distance: {np.linalg.norm(self.bottle.get_pose().p - self.target_pose)}")

    return np.linalg.norm(self.bottle.get_pose().p - self.target_pose) < eps
```

### 7.4 指令生成失败

**症状**：`KeyError: '{A}' not found`

**解决方案**：
确保 `play_once()` 返回的 `info` 字典包含所有指令模板中使用的占位符：

```python
# 错误示例
self.info["info"] = {
    "{A}": "001_bottle/base2",
    # 缺少 "{B}"
}

# 正确示例
self.info["info"] = {
    "{A}": "001_bottle/base2",
    "{B}": "003_cup/base1",
}
```

## 九、总结

RoboTwin 的新任务定义遵循**模块化、参数化**的设计原则：

### 核心要素

1. **Python 任务类**：定义逻辑、动作、成功条件
2. **Info 字典**：连接任务、场景、指令的桥梁
3. **指令模板**：参数化的自然语言描述
4. **配置文件**：步数限制、域随机化

### 关键优势

- **可扩展性**：50+ 任务统一接口
- **可复现性**：scene_info 精确记录场景参数
- **语言多样性**：每个任务 1,500+ 指令变体
- **灵活性**：支持 5 种机器人、单/双臂模式

### 设计理念

```
任务逻辑 ←→ 场景参数 ←→ 语言指令
   ↓              ↓              ↓
 play_once()   scene_info.json  instruction.json
   ↓              ↓              ↓
 expert_data   reusable       diverse
```

通过遵循本文档的指南，开发者可以快速定义高质量、可评测的双臂机器人操作任务，为策略研究和 sim-to-real 迁移提供强大的基准平台。
