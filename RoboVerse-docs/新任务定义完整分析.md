# RoboVerse 新任务定义完整分析

## 概述

RoboVerse 是一个**统一的机器人学习平台和基准测试框架**，支持多个仿真器（Isaac Lab, MuJoCo, SAPIEN, Genesis, PyBullet, cuRobo）。与 RoboTwin 相比，RoboVerse 采用了更**通用化、配置驱动**的任务定义方式。

```
┌─────────────────────────────────────────────────────────────────────┐
│ RoboVerse 统一任务架构                                       │
│                                                                  │
│  ┌──────────────────────────────────────────────────────────┐    │
│  │ 1. 任务类 (Task Class)                        │    │
│  │    roboverse_pack/tasks/{task_type}/{task}.py     │    │
│  │    ├─ @register_task() 装饰器注册              │    │
│  │    ├─ ScenarioCfg 场景配置 (class 变量)         │    │
│  │    ├─ _get_initial_states() 初始状态            │    │
│  │    ├─ _terminated() 成功条件                     │    │
│  │    ├─ _reward() 奖励函数                       │    │
│  │    └─ (可选) step()/reset() 自定义逻辑        │    │
│  └──────────────────────────────────────────────────────────┘    │
│                          │                                       │
│  ┌──────────────────────────────────────────────────────────┐    │
│  │ 2. 场景配置 (Scenario Configuration)              │    │
│  │    metasim/scenario/scenario.py (ScenarioCfg)         │    │
│  │    ├─ objects: 物体列表 (RigidObjCfg, ...)     │    │
│  │    ├─ robots: 机器人列表 (RobotCfg, ...)          │    │
│  │    ├─ cameras: 相机列表 (CameraCfg, ...)          │    │
│  │    ├─ lights: 光源列表 (LightCfg, ...)            │    │
│  │    ├─ sim_params: 仿真参数 (SimParamCfg)          │    │
│  │    └─ simulator: 仿真器选择                        │    │
│  └──────────────────────────────────────────────────────────┘    │
│                          │                                       │
│  ┌──────────────────────────────────────────────────────────┐    │
│  │ 3. 基础环境 (Base Environment)                    │    │
│  │    metasim/task/base.py (BaseTaskEnv)               │    │
│  │    ├─ TensorState 统一状态表示                    │    │
│  │    ├─ step() 环境步进                          │    │
│  │    ├─ reset() 环境重置                          │    │
│  │    └─ 回调机制 (pre/post_physics_step_callback)   │    │
│  └──────────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────────────┘
```

## 一、核心架构设计

### 1.1 三层抽象设计

```
┌─────────────────────────────────────────────────────────────────┐
│ 第1层：MetaSim (底层仿真器抽象)                      │
│    metasim/                                           │
│    ├─ sim/ 仿真器接口 (IsaacLab, MuJoCo, ...)    │
│    ├─ scenario/ 场景配置 (ScenarioCfg)               │
│    └─ task/ 任务基类 (BaseTaskEnv)                  │
└─────────────────────────────────────────────────────────────────┘
                    │
                    ▼
┌─────────────────────────────────────────────────────────────────┐
│ 第2层：Task Packages (任务包)                          │
│    roboverse_pack/                                      │
│    ├─ tasks/{task_type}/ 具体任务实现          │
│    │   ├─ libero_90/ LIBERO 90 任务                 │
│    │   ├─ rlbench/ RLBench 任务                    │
│    │   ├─ pick_place/ 抓取放置任务                  │
│    │   └─ ... (其他任务集)                         │
│    └─ @register_task() 装饰器注册机制               │
└─────────────────────────────────────────────────────────────────┘
                    │
                    ▼
┌─────────────────────────────────────────────────────────────────┐
│ 第3层：Task Class (具体任务)                             │
│    继承自 BaseTaskEnv 或其子类                       │
│    ├─ 定义 ScenarioCfg (类变量)                     │
│    ├─ 重写核心方法                                 │
│    └─ 实现任务逻辑                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 与 RoboTwin 的关键区别

| 维度 | RoboTwin | RoboVerse |
|-------|-----------|-----------|
| **仿真器** | SAPIEN 单一 | 多仿真器 (IsaacLab, MuJoCo, SAPIEN, Genesis, PyBullet, cuRobo) |
| **场景配置** | 硬编码在 `setup_demo()` 中 | 配置化 `ScenarioCfg` 类 |
| **状态表示** | 各类 getter/setter (get_pose(), set_pose()) | 统一 `TensorState` 结构 |
| **机器人** | 单一机器人配置文件 | 多机器人支持，统一配置接口 |
| **任务注册** | 动态导入 `class_decorator()` | 装饰器 `@register_task()` + 全局注册表 |
| **初始化** | 在 `__init__` 中手动设置 | 配置驱动，自动实例化仿真器 |
| **数据格式** | 多文件 (scene_info.json, task_instruction.json) | 统一数据结构，支持轨迹文件 |
| **并行环境** | 单环境串行执行 | 批量并行环境 (`num_envs`) |
| **随机化** | 集中在 config 中管理 | 分散在各层 (ScenarioCfg → objects → randomization) |
| **回调系统** | 无 | 前置/后置回调 (`pre/post_physics_step_callback`) |

## 二、任务定义的核心组件

### 2.1 任务注册机制（装饰器模式）

RoboVerse 使用**装饰器模式**注册任务：

```python
from metasim.task.registry import register_task

@register_task("task_type.task_name", "task_name")
class MyTask(BaseTaskEnv):
    """任务类定义"""
    ...
```

**注册特性**：
- 支持多个名称（短名和长名）
- 全局注册表 `TASK_REGISTRY`（字典结构）
- 大小写不敏感的名称查找
- 自动任务发现机制

**注册流程**：
```python
# 1. 定义装饰器
@register_task("libero_90.kitchen_scene1_put_black_bowl_on_plate")
class LiberoTask(...):
    ...

# 2. 通过注册表获取任务
from metasim.task.registry import get_task_class
task_cls = get_task_class("libero_90.kitchen_scene1_put_black_bowl_on_plate")

# 3. 实例化环境
scenario = task_cls.scenario.update(num_envs=2)
env = task_cls(scenario=scenario, device="cuda")
```

### 2.2 场景配置（ScenarioCfg）

**场景配置作为类变量**，定义任务的所有静态配置：

```python
class LiberoKitchenTask(BaseTaskEnv):
    # ========================
    # 场景配置（类变量）
    # ========================
    scenario = ScenarioCfg(
        # 物体列表
        objects=[
            RigidObjCfg(
                name="akita_black_bowl",
                usd_path="assets/akita_black_bowl.usd",
                urdf_path="assets/akita_black_bowl.urdf",
                mjcf_path="assets/akita_black_bowl.xml",
                physics=PhysicStateType.RIGIDBODY,
            ),
            RigidObjCfg(
                name="plate",
                usd_path="assets/plate.usd",
                physics=PhysicStateType.RIGIDBODY,
            ),
            ArticulationObjCfg(
                name="wooden_cabinet",
                fix_base_link=True,
                usd_path="assets/wooden_cabinet.usd",
            ),
        ],

        # 机器人列表
        robots=["franka"],  # 也可以使用自定义机器人配置

        # 仿真参数
        sim_params=SimParamCfg(dt=0.005),
        decimation=4,  # 渲染降采样率

        # 运行时配置
        simulator="mujoco",  # 或 "isaaclab", "sapien3", "genesis", ...
        num_envs=1,
        headless=False,
    )

    # ========================
    # 任务参数
    # ========================
    max_episode_steps = 300
    task_desc = "Put the black bowl on the plate"

    # 工作空间配置
    workspace_name = "kitchen_table"
    workspace_offset = (0, 0, 0)

    # 轨迹文件（可选）
    traj_filepath = "assets/trajs/libero90/kitchen_scene1_traj_v2.pkl"
```

**配置组件详解**：

| 组件 | 配置类 | 作用 |
|-------|---------|------|
| **物体** | `RigidObjCfg` | 刚体物体（碗、方块、物体等） |
| | `ArticulationObjCfg` | 关节物体（橱柜、抽屉、门等） |
| **机器人** | `RobotCfg` 或 `str` | 机器人定义（Franka, UR5, Panda 等） |
| **相机** | `CameraCfg` | RGB/深度相机配置 |
| **光源** | `BaseLightCfg`, `DistantLightCfg` | 点光源/远光源 |
| **地面** | `GroundCfg` | 地面/桌子配置 |
| **仿真参数** | `SimParamCfg` | dt、重力、解算器等 |
| **渲染** | `RenderCfg` | 渲染器、分辨率等 |

### 2.3 BaseTaskEnv 核心方法

每个任务必须继承自 `BaseTaskEnv` 并实现以下方法：

```python
from metasim.task.base import BaseTaskEnv
from metasim.types import TensorState, Reward, Termination, TimeOut

class MyTask(BaseTaskEnv):

    # ========================
    # 1. 场景配置（类变量）
    # ========================
    scenario = ScenarioCfg(...)

    # ========================
    # 2. 初始化
    # ========================
    def __init__(self, scenario: ScenarioCfg, device: str | torch.device | None = None) -> None:
        super().__init__(scenario, device)
        # 自定义成员变量
        self.step_count = 0

    # ========================
    # 3. 设置初始状态
    # ========================
    def _get_initial_states(self) -> list[dict]:
        """
        返回每个环境的初始状态

        Returns:
            list[dict] of length num_envs
            Each dict contains:
                - "objects": {obj_name: {pos, rot, ...}}
                - "robots": {robot_name: {pos, rot, joint_pos, ...}}
                - "cameras": {camera_name: {pos, quat, ...}}
                - "extras": {...}
        """
        return [
            {
                "objects": {
                    "target": {
                        "pos": torch.tensor([0.5, 0.0, 0.3]),
                        "rot": torch.tensor([1.0, 0.0, 0.0, 0.0]),  # 四元数 w,x,y,z
                    },
                },
                "robots": {
                    "franka": {
                        "pos": torch.tensor([0.0, 0.0, 0.0]),
                        "rot": torch.tensor([1.0, 0.0, 0.0, 0.0]),
                        "joint_pos": {
                            "panda_joint1": 0.0,
                            "panda_joint2": -0.5,
                            ...
                        },
                    },
                },
                "cameras": {},
                "extras": {},
            }
            for _ in range(self.num_envs)
        ]

    # ========================
    # 4. 成功条件
    # ========================
    def _terminated(self, states: TensorState) -> torch.Tensor:
        """
        检查任务是否成功

        Args:
            states: 当前环境状态 (TensorState)

        Returns:
            Boolean tensor [num_envs], True 表示成功
        """
        # 示例：端部末端到达目标
        ee_pos = states.robots["franka"].root_state[:, 0:3]
        target_pos = states.objects["target"].root_state[:, 0:3]
        distance = torch.norm(ee_pos - target_pos, dim=-1)
        return distance < 0.05

    # ========================
    # 5. 奖励函数（可选）
    # ========================
    def _reward(self, states: TensorState) -> Reward:
        """
        计算奖励

        Returns:
            奖励张量 [num_envs]
        """
        # 默认返回零奖励
        return torch.zeros(self.num_envs, dtype=torch.float32, device=self.device)

    # ========================
    # 6. 观测空间（可选）
    # ========================
    def _observation_space(self) -> gym.spaces.Space:
        """返回观测空间"""
        return gym.spaces.Box(low=-np.inf, high=np.inf, shape=(obs_dim,))

    # ========================
    # 7. 动作空间（可选）
    # ========================
    def _action_space(self) -> gym.spaces.Space:
        """返回动作空间"""
        return gym.spaces.Box(low=-1.0, high=1.0, shape=(action_dim,))

    # ========================
    # 8. 可选：自定义 step() 和 reset()
    # ========================
    def step(self, actions: Action) -> tuple[Obs, Reward, Success, TimeOut, Info]:
        """
        自定义步进逻辑（覆盖默认行为）

        可用于：
        - 动作归一化/反归一化
        - 端部末端控制映射
        - 自定义控制逻辑
        """
        # 调用父类 step
        return super().step(actions)

    def reset(self, states=None, env_ids=None) -> tuple[Obs, Info]:
        """
        自定义重置逻辑

        可用于重置自定义成员变量
        """
        states, info = super().reset(states, env_ids)

        # 重置自定义变量
        if env_ids is None:
            self.step_count = 0
        else:
            self.step_count[env_ids] = 0

        return states, info
```

### 2.4 TensorState 统一状态表示

RoboVerse 使用 `TensorState` 作为核心数据结构，统一访问所有仿真状态：

```python
# TensorState 结构
states = env.reset()

# 访问物体状态
obj_pos = states.objects["target"].root_state[:, 0:3]      # [num_envs, 3]
obj_quat = states.objects["target"].root_state[:, 3:7]      # [num_envs, 4]
obj_lin_vel = states.objects["target"].root_state[:, 7:10]   # [num_envs, 3]
obj_ang_vel = states.objects["target"].root_state[:, 10:13]  # [num_envs, 3]

# 访问机器人状态
robot_joint_pos = states.robots["franka"].joint_pos  # [num_envs, num_joints]
robot_joint_vel = states.robots["franka"].joint_vel  # [num_envs, num_joints]
robot_root_pos = states.robots["franka"].root_state[:, 0:3]  # [num_envs, 3]

# 访问相机状态
camera_rgb = states.cameras["head_camera"].rgb  # [num_envs, H, W, 3]
camera_depth = states.cameras["head_camera"].depth  # [num_envs, H, W]
camera_pos = states.cameras["head_camera"].pos  # [num_envs, 3]
```

**TensorState 结构**：

```
TensorState
├─ objects: Dict[str, ObjectState]
│   └─ ObjectState
│       ├─ root_state: [num_envs, 13] = [pos(3), quat(4), lin_vel(3), ang_vel(3)]
│       ├─ joint_pos: [num_envs, num_joints] (对于关节物体）
│       └─ body_names: List[str]
├─ robots: Dict[str, RobotState]
│   └─ RobotState
│       ├─ root_state: [num_envs, 13]
│       ├─ joint_pos: [num_envs, num_joints]
│       ├─ joint_vel: [num_envs, num_joints]
│       ├─ joint_pos_target: [num_envs, num_joints]
│       └─ body_names: List[str]
├─ cameras: Dict[str, CameraState]
│   └─ CameraState
│       ├─ rgb: [num_envs, H, W, 3]
│       ├─ depth: [num_envs, H, W]
│       ├─ pos: [num_envs, 3]
│       └─ quat_world: [num_envs, 4]
└─ extras: Dict[str, Any] (自定义数据）
```

                            "panda_joint1": 0.0,

                "extras": {},

    # 4. 实现成功条件
    # ========================
    def _terminated(self, states: TensorState) -> torch.Tensor:
        """检查任务是否完成"""
        # 示例：末端执行器到达目标
        ee_pos = states.robots["franka"].root_state[:, 0:3]

    # 5. 可选：观测空间

    # ========================
    # 6. 可选：自定义 step
    # ========================
    def step(self, actions: torch.Tensor):
        """自定义步进逻辑"""
        # 示例：动作归一化

        return super().step(actions)

### 3.2 LIBERO 90 任务示例

```python
from __future__ import annotations

import torch

from metasim.constants import PhysicStateType
from metasim.scenario.objects import ArticulationObjCfg, RigidObjCfg
from metasim.scenario.scenario import ScenarioCfg
from metasim.task.registry import register_task
from metasim.types import TensorState
from .libero_90_base import Libero90BaseTask
from metasim.utils.demo_util import get_traj

# ========================
# 1. 注册任务
# ========================
@register_task(
    "libero_90.kitchen_scene1_put_black_bowl_on_plate"
)
class LiberoKitchen1PutBowlOnPlateTask(Libero90BaseTask):
    """LIBERO 厨房场景：将黑碗放在盘子上"""

    # ========================
    # 2. 场景配置
    # ========================
    scenario = ScenarioCfg(
        objects=[
            # 可移动物体
            RigidObjCfg(
                name="akita_black_bowl",
                usd_path="roboverse_data/assets/libero/akita_black_bowl.usd",
                urdf_path="roboverse_data/assets/libero/akita_black_bowl.urdf",
                mjcf_path="roboverse_data/assets/libero/akita_black_bowl.xml",
                physics=PhysicStateType.RIGIDBODY,
            ),
            RigidObjCfg(
                name="plate",
                usd_path="roboverse_data/assets/libero/plate.usd",
                urdf_path="roboverse_data/assets/libero/plate.urdf",
                mjcf_path="roboverse_data/assets/libero/plate.xml",
                physics=PhysicStateType.RIGIDBODY,
            ),
            # 固定装置（关节物体）
            ArticulationObjCfg(
                name="wooden_cabinet",
                fix_base_link=True,
                usd_path="roboverse_data/assets/libero/wooden_cabinet.usd",
            ),
        ],
        robots=["franka"],
    )

    # ========================
    # 3. 任务参数
    # ========================
    max_episode_steps = 300  # LIBERO 90 任务更复杂
    task_desc = "Put the black bowl on the plate"

    # 工作空间配置
    workspace_name = "kitchen_table"
    workspace_offset = (0, 0, 0)
    workspace_size = (1.0, 1.2, 0.05)

    # 轨迹文件路径
    traj_filepath = "roboverse_data/trajs/libero90/kitchen_scene1_traj_v2.pkl"

    # ========================
    # 4. 成功条件
    # ========================
    def _terminated(self, states: TensorState) -> torch.Tensor:
        """任务成功检查器"""
        bowl_pos = states.objects["akita_black_bowl"].root_state[:, 0:3]  # (N, 3)
        plate_pos = states.objects["plate"].root_state[:, 0:3]  # (N, 3)

        # 检查碗是否在盘子正上方的小区域内
        range_threshold = 0.06  # xy 平面半径范围
        height_threshold = 0.03  # 盘子上方高度容差

        # 计算碗和盘子之间的 xy 距离
        xy_distance = torch.norm(bowl_pos[:, 0:2] - plate_pos[:, 0:2], dim=-1)  # (N,)

        # 计算高度差（碗 z - 盘子 z）
        height_diff = bowl_pos[:, 2] - plate_pos[:, 2]  # (N,)

        # 检查条件：xy 距离 < 范围 AND 0 < 高度差 < 阈值
        xy_close = xy_distance < range_threshold  # (N,)
        height_valid = (height_diff > 0) & (height_diff < height_threshold)  # (N,)

        is_on_plate = xy_close & height_valid  # (N,)

        return is_on_plate

    # ========================
    # 5. 可选：重置逻辑
    # ========================
    def reset(self, states=None, env_ids=None):
        """跳过检查器重置"""
        states = super(Libero90BaseTask, self).reset(states, env_ids)
        return states
```

## 九、总结

RoboVerse 的新任务定义机制是一个**高度模块化、配置驱动、多仿真器支持**的设计：

### 核心优势

1. **通用性**：支持 10+ 个外部任务集（LIBERO, RLBench, ManiSkill 等）
2. **多仿真器**：支持 6 种仿真器（Isaac Lab, MuJoCo, SAPIEN, Genesis, PyBullet, cuRobo）
3. **批量并行**：原生支持批量环境，GPU 加速训练
4. **统一状态**：TensorState 结构化状态表示，易于扩展
5. **Gymnasium 兼容**：标准接口，易于集成 RL 算法
6. **配置驱动**：ScenarioCfg 类变量，无需硬编码
7. **装饰器注册**：`@register_task()` 简洁的任务注册机制
8. **回调系统**：前置/后置回调，灵活的自定义行为
9. **轨迹加载**：支持从演示轨迹初始化环境

### 设计理念

```
任务类（配置 + 逻辑）
    ├─ ScenarioCfg（场景配置，类变量）
    ├─ _get_initial_states()（初始状态）
    ├─ _terminated()（成功条件）
    └─ _reward()（奖励函数）

              ↓

批量并行环境（向量化操作）
    ├─ TensorState（统一状态结构）
    ├─ 批量 step()
    └─ GPU 加速（CUDA 支持）

              ↓

多仿真器统一接口
    ├─ Isaac Lab（NVIDIA）
    ├─ MuJoCo（DeepMind）
    ├─ SAPIEN（SAPIEN）
    ├─ Genesis（MIT）
    ├─ PyBullet（物理引擎）
    └─ cuRobo（华为）
```

### 任务定义三步法

1. **定义场景配置**：创建 `ScenarioCfg`，指定物体、机器人、仿真器
2. **实现核心方法**：
   - `_get_initial_states()`: 设置初始状态
   - `_terminated()`: 定义成功条件
   - （可选）`_reward()`: 奖励函数
3. **注册任务**：使用 `@register_task()` 装饰器注册到全局注册表

通过遵循此模式，开发者可以快速为 RoboVerse 添加新任务，支持多个仿真器和外部任务集，实现统一的机器人学习基准测试。
