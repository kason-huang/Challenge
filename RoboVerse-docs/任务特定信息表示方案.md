# 任务特定信息表示方案

## 概述

本文档定义一个**通用的任务信息表示机制**，支持不同类型的机器人任务（导航、操作、人形等），并能够与 RoboTwin 和 RoboVerse 两种框架兼容。

---

## 一、任务分类与信息需求

### 1.1 任务类型枚举

```python
from enum import Enum

from dataclasses import dataclass, field

### 1.2 通用任务信息结构

```python
@dataclass
class TaskInfo:
    """通用任务信息结构
    
    设计目标：
    1. 支持不同任务类型（导航、操作、人形等）
    2. 兼容 RoboTwin 的 info["info"] 格式
    3. 兼容 RoboVerse 的 TensorState 结构
    4. 扩展性强，易于添加新任务类型
    """
    
    # ====================
    # 基础信息
    # ====================
    task_type: TaskType = TaskType.PICK_PLACE
    task_name: str = "pick_place"
    task_description: str = "Pick up the object and place it on the target"
    
    # ====================
    # 目标信息（根据任务类型不同）
    # ====================
    goal: GoalInfo = None  # 统一的目标表示
    
    # ====================
    # 约束信息
    # ====================
    max_episode_steps: int = 1000
    success_threshold: Dict[str, float] = field(default_factory=dict)
    time_limit: Optional[float] = None
    
    # ====================
    # 元数据
    # ====================
    difficulty: str = "medium"  # easy, medium, hard
    robot_type: Optional[str] = None  # single_arm, dual_arm, humanoid
    scene_type: Optional[str] = None   # kitchen, office, warehouse


@dataclass
class GoalInfo:
    """目标信息基类
    
    根据任务类型，GoalInfo 包含不同的字段
    """
    
    goal_type: TaskType
    
    # 目标可以有不同形式
    point_goal: Optional[PointGoal] = None
    object_goal: Optional[ObjectGoal] = None
    sequence_goal: Optional[SequenceGoal] = None
    region_goal: Optional[RegionGoal] = None


# ====================
# 不同类型的目标
# ====================

@dataclass
class PointGoal:
    """点目标（用于导航任务）
    
    示例：移动机器人到坐标 (0.5, 0.0, 0.3)
    """
    position: np.ndarray  # [x, y, z]
    tolerance: float = 0.05  # 容差（米）
    frame: str = "world"  # world, base_link, end_effector


@dataclass
class ObjectGoal:
    """物体目标（用于操作任务）
    
    示例：抓取 "red_block" 并放置到 "plate"
    """
    target_object: str  # 目标物体名称
    target_pose: Optional[np.ndarray] = None  # [x, y, z, qx, qy, qz, qw]
    grasp_point: Optional[np.ndarray] = None  # 抓取点（可选）
    functional_constraint: Optional[str] = None  # 功能约束：on_top_of, inside, adjacent_to
    object_state_constraint: Optional[Dict[str, str]] = None  # 状态约束：{pose: "upright", "grasped": True}


@dataclass
class SequenceGoal:
    """序列目标（用于多步骤任务）
    
    示例：先抓取物体 A，然后抓取物体 B，最后堆叠
    """
    steps: List[OperationStep]
    final_state: Optional[StateGoal] = None
    
@dataclass
class OperationStep:
    """操作步骤定义"""
    step_index: int
    operation: str  # grasp, place, push, open
    target_object: str
    target_location: Optional[np.ndarray] = None
    parameters: Dict = field(default_factory=dict)


@dataclass
class RegionGoal:
    """区域目标（用于区域导航任务）
    
    示例：移动到桌面上方区域
    """
    region_bounds: np.ndarray  # [[x_min, y_min, z_min], [x_max, y_max, z_max]]
    region_center: Optional[np.ndarray] = None
    region_type: str = "box"  # box, sphere, cylinder


@dataclass
class StateGoal:
    """状态目标（用于特定状态要求）
    
    示例：保持物体直立的姿态
    """
    object_name: str
    required_state: Dict[str, str]  # {"pose": "upright", "grasped": True, "contact": True}
    state_confidence: float = 0.9  # 置信度（0-1）
```

## 二、RoboTwin 兼容性设计

### 2.1 映射到 info["info"] 格式

RoboTwin 使用占位符系统（`{A}`, `{B}`, `{a}`, `{b}`），我们需要设计一个兼容层：

```python
class RoboTwinTaskInfoConverter:
    """将通用任务信息转换为 RoboTwin 的 info["info"] 格式"""
    
    @staticmethod
    def convert_to_info_dict(task_info: TaskInfo) -> Dict[str, str]:
        """
        将通用任务信息转换为 RoboTwin 兼容的 info 字典
        
        Args:
            task_info: 通用任务信息
            
        Returns:
            Dict[str, str]: RoboTwin 的 info["info"] 格式
        """
        info_dict = {}
        
        # 根据任务类型转换
        if task_info.task_type == TaskType.PICK_PLACE:
            info_dict = RoboTwinTaskInfoConverter._convert_pick_place(task_info)
        elif task_info.task_type == TaskType.STACKING:
            info_dict = RoboTwinTaskInfoConverter._convert_stacking(task_info)
        elif task_info.task_type == TaskType.NAVIGATION:
            info_dict = RoboTwinTaskInfoConverter._convert_navigation(task_info)
        else:
            # 默认：使用任务名称作为标识
            info_dict = {"task_name": task_info.task_name}
        
        return info_dict
    
    @staticmethod
    def _convert_pick_place(task_info: TaskInfo) -> Dict[str, str]:
        """转换抓取-放置任务"""
        if isinstance(task_info.goal, ObjectGoal):
            # 示例：抓取红色方块并放置到盘子
            info_dict = {
                "{A}": task_info.goal.target_object,  # 被抓取的物体
                "{B}": task_info.goal.functional_constraint if task_info.goal.functional_constraint else "target_location",  # 目标位置描述
                "{a}": "left",  # 使用的机械臂（固定）
                "{b}": "left",  # 使用的机械臂
            }
        else:
            # 简化版本
            info_dict = {
                "{A}": "target_object",
                "{B}": "target_location",
            }
        return info_dict
    
    @staticmethod
    def _convert_stacking(task_info: TaskInfo) -> Dict[str, str]:
        """转换堆叠任务"""
        if isinstance(task_info.goal, SequenceGoal):
            objects = [step.target_object for step in task_info.goal.steps]
            info_dict = {
                "{A}": objects[0],
                "{B}": objects[1],
                "{C}": objects[2] if len(objects) > 2 else None,
            }
        return info_dict
    
    @staticmethod
    def _convert_navigation(task_info: TaskInfo) -> Dict[str, str]:
        """转换导航任务"""
        if isinstance(task_info.goal, PointGoal):
            info_dict = {
                "{A}": f"target_position_{task_info.goal.position}",
            }
        elif isinstance(task_info.goal, RegionGoal):
            info_dict = {
                "{A}": f"target_region_{task_info.goal.region_type}",
            }
        else:
            info_dict = {}
        return info_dict
```

### 2.2 RoboTwin 任务扩展示例

```python
from .base_task import Base_Task
from .utils import create_actor
import numpy as np
from typing import Dict

# 导入通用任务信息
from task_info_definition import (
    TaskInfo, TaskType, PointGoal, ObjectGoal, GoalInfo

class navigate_to_target(Base_Task):
    """导航任务：移动到目标点"""
    
    def setup_demo(self, **kwargs):
        super()._init_task_env_(**kwargs)
        self.load_actors()
    
    def load_actors(self):
        # 创建目标标记（可视化目标位置）
        self.target_marker = create_actor(
            scene=self,
            pose=np.array([0.5, 0.0, 0.3]),
            modelname="target_marker",
            model_id=0,
        )
    
    def play_once(self):
        # 执行导航动作（使用底层 API）
        target_pos = [0.5, 0.0, 0.3]
        self.robot.navigate_to(target_pos)
        
        # ====================
        # 关键：定义任务信息
        # ====================
        task_info = TaskInfo(
            task_type=TaskType.NAVIGATION,
            task_name="navigate_to_target",
            task_description="Navigate to the target point",
            goal=PointGoal(
                goal_type=TaskType.NAVIGATION,
                position=np.array(target_pos),
                tolerance=0.05,
                frame="world",
            ),
            max_episode_steps=500,
        )
        
        # 转换为 RoboTwin 兼容格式
        self.info["info"] = RoboTwinTaskInfoConverter.convert_to_info_dict(task_info)
        
        return self.info
    
    def check_success(self):
        # 检查机器人是否到达目标
        ee_pos = self.robot.get_end_effector_pose().p
        target_pos = self.target_marker.get_pose().p
        distance = np.linalg.norm(ee_pos - target_pos)
        return distance < 0.05


class pick_and_place_object(Base_Task):
    """抓取-放置任务"""
    
    def setup_demo(self, **kwargs):
        super()._init_task_env_(**kwargs)
        self.load_actors()
    
    def load_actors(self):
        # 创建目标物体和目标位置标记
        self.target_object = create_actor(
            scene=self,
            pose=np.array([0.3, -0.2, 0.74]),
            modelname="red_block",
            model_id=0,
        )
        
        self.target_location_marker = create_actor(
            scene=self,
            pose=np.array([0.5, 0.0, 0.74]),
            modelname="target_location_marker",
            model_id=0,
        )
    
    def play_once(self):
        # 执行抓取-放置动作
        arm_tag = self.robot.get_nearest_arm(self.target_object.get_pose().p[:2])
        
        self.robot.grasp(self.target_object, arm_tag=arm_tag)
        self.robot.lift(self.target_object, arm_tag=arm_tag)
        self.robot.move_to(self.target_location_marker.get_pose().p[:2], arm_tag=arm_tag)
        self.robot.place(self.target_object, arm_tag=arm_tag)
        
        # ====================
        # 关键：定义任务信息
        # ====================
        task_info = TaskInfo(
            task_type=TaskType.PICK_PLACE,
            task_name="pick_and_place_object",
            task_description="Pick up the red block and place it at target location",
            goal=ObjectGoal(
                goal_type=TaskType.PICK_PLACE,
                target_object="red_block",
                target_pose=self.target_location_marker.get_pose(),
                grasp_point=self.target_object.get_grasp_point(),
                functional_constraint="on_top_of",
            ),
            max_episode_steps=600,
        )
        
        # 转换为 RoboTwin 兼容格式
        self.info["info"] = RoboTwinTaskInfoConverter.convert_to_info_dict(task_info)
        
        return self.info
    
    def check_success(self):
        # 检查物体是否在目标位置
        obj_pos = self.target_object.get_pose().p
        target_pos = self.target_location_marker.get_pose().p
        distance = np.linalg.norm(obj_pos[:2] - target_pos[:2])
        return distance < 0.05


class stack_objects(Base_Task):
    """堆叠任务：将多个物体按顺序堆叠"""
    
    def setup_demo(self, **kwargs):
        super()._init_task_env_(**kwargs)
        self.load_actors()
    
    def load_actors(self):
        # 创建三个物体
        self.objects = [
            create_actor(scene=self, pose=np.array([0.3, -0.2, 0.74]), 
                     modelname="red_cube", model_id=0),
            create_actor(scene=self, pose=np.array([0.4, -0.2, 0.74]), 
                     modelname="green_cube", model_id=0),
            create_actor(scene=self, pose=np.array([0.5, -0.2, 0.74]), 
                     modelname="blue_cube", model_id=0),
        ]
    
    def play_once(self):
        # 按顺序堆叠物体
        stack_order = ["red_cube", "green_cube", "blue_cube"]
        
        for obj_name in stack_order:
            obj = next(o for o in self.objects if o.get_name() == obj_name)
            arm_tag = self.robot.get_nearest_arm(obj.get_pose().p[:2])
            
            self.robot.grasp(obj, arm_tag=arm_tag)
            self.robot.lift(obj, arm_tag=arm_tag)
            
            # 最后一个物体不需要移动
            if obj_name != stack_order[-1]:
                # 移动到上一个物体的位置
                target_z = 0.74 + len(stack_order) * 0.05  # 每个物体高度 5cm
                target_pos = np.array([0.4, -0.2, target_z])
                self.robot.move_to(target_pos[:2], arm_tag=arm_tag)
            
            self.robot.place(obj, arm_tag=arm_tag)
        
        # ====================
        # 关键：定义任务信息
        # ====================
        task_info = TaskInfo(
            task_type=TaskType.STACKING,
            task_name="stack_objects",
            task_description="Stack objects in order: red on bottom, green in middle, blue on top",
            goal=SequenceGoal(
                goal_type=TaskType.STACKING,
                steps=[
                    OperationStep(
                        step_index=0,
                        operation="grasp",
                        target_object="red_cube",
                    ),
                    OperationStep(
                        step_index=1,
                        operation="place_on_top",
                        target_object="red_cube",
                        target_location=np.array([0.4, -0.2, 0.79]),
                    ),
                    OperationStep(
                        step_index=2,
                        operation="grasp",
                        target_object="green_cube",
                    ),
                    OperationStep(
                        step_index=3,
                        operation="place_on_top",
                        target_object="green_cube",
                        target_location=np.array([0.4, -0.2, 0.84]),
                    ),
                ],
            ),
            max_episode_steps=900,
        )
        
        # 转换为 RoboTwin 兼容格式
        self.info["info"] = RoboTwinTaskInfoConverter.convert_to_info_dict(task_info)
        
        return self.info
    
    def check_success(self):
        # 检查堆叠是否成功
        red_pos = self.objects[0].get_pose().p
        green_pos = self.objects[1].get_pose().p
        blue_pos = self.objects[2].get_pose().p
        
        # 检查高度顺序
        condition1 = abs(blue_pos[2] - green_pos[2] - 0.05) < 0.02
        condition2 = abs(green_pos[2] - red_pos[2] - 0.05) < 0.02
        
        # 检查水平对齐
        eps = 0.03
        condition3 = np.all(abs(red_pos[:2] - green_pos[:2]) < eps)
        condition4 = np.all(abs(green_pos[:2] - blue_pos[:2]) < eps)
        
        return condition1 and condition2 and condition3 and condition4

## 三、RoboVerse 兼容性设计

### 3.1 映射到 TensorState 格式

RoboVerse 使用 TensorState 作为统一的状态表示，我们需要设计一个转换层：

```python
import torch
from metasim.types import TensorState
from metasim.task.base import BaseTaskEnv
from metasim.scenario.scenario import ScenarioCfg
from metasim.scenario.objects import RigidObjCfg
from metasim.task.registry import register_task
from task_info_definition import TaskInfo, TaskType, PointGoal, ObjectGoal, GoalInfo


class RoboVerseTaskInfoAdapter:
    """将通用任务信息适配到 RoboVerse 环境
    
    提供以下功能：
    1. 从 TaskInfo 生成初始状态
    2. 从 TaskInfo 实现 success 判断逻辑
    3. 提供 reward 计算辅助函数
    """
    
    @staticmethod
    def generate_initial_states(
        task_info: TaskInfo,
        num_envs: int,
        device: torch.device
    ) -> list[dict]:
        """
        根据任务信息生成初始状态
        
        Args:
            task_info: 任务信息
            num_envs: 环境数量
            device: 计算设备
            
        Returns:
            list[dict]: RoboVerse 兼容的初始状态列表
        """
        initial_states = []
        
        for env_id in range(num_envs):
            state_dict = {
                "objects": {},
                "robots": {},
                "cameras": {},
                "extras": {},
            }
            
            # 根据任务类型生成状态
            if task_info.task_type == TaskType.NAVIGATION:
                state_dict = RoboVerseTaskInfoAdapter._generate_navigation_state(
                    state_dict, task_info, env_id, device
                )
            elif task_info.task_type == TaskType.PICK_PLACE:
                state_dict = RoboVerseTaskInfoAdapter._generate_pick_place_state(
                    state_dict, task_info, env_id, device
                )
            elif task_info.task_type == TaskType.STACKING:
                state_dict = RoboVerseTaskInfoAdapter._generate_stacking_state(
                    state_dict, task_info, env_id, device
                )
            else:
                # 默认：使用简单的物体放置
                state_dict = RoboVerseTaskInfoAdapter._generate_default_state(
                    state_dict, task_info, env_id, device
                )
            
            initial_states.append(state_dict)
        
        return initial_states
    
    @staticmethod
    def generate_success_checker(
        task_info: TaskInfo
    ):
        """
        生成成功检查器函数
        
        Args:
            task_info: 任务信息
            
        Returns:
            Callable: 接受 TensorState，返回 bool 张量
        """
        if task_info.task_type == TaskType.NAVIGATION:
            return RoboVerseTaskInfoAdapter._navigation_success_checker(task_info)
        elif task_info.task_type == TaskType.PICK_PLACE:
            return RoboVerseTaskInfoAdapter._pick_place_success_checker(task_info)
        elif task_info.task_type == TaskType.STACKING:
            return RoboVerseTaskInfoAdapter._stacking_success_checker(task_info)
        else:
            return lambda states: torch.zeros(states.shape[0], dtype=torch.bool)
    
    @staticmethod
    def generate_reward_function(
        task_info: TaskInfo
    ):
        """
        生成奖励函数
        
        Args:
            task_info: 任务信息
            
        Returns:
            Callable: 接受 TensorState，返回 reward 张量
        """
        if task_info.task_type == TaskType.NAVIGATION:
            return RoboVerseTaskInfoAdapter._navigation_reward_function(task_info)
        elif task_info.task_type == TaskType.PICK_PLACE:
            return RoboVerseTaskInfoAdapter._pick_place_reward_function(task_info)
        else:
            return lambda states: torch.zeros(states.shape[0], dtype=torch.float32)
    
    @staticmethod
    def _generate_navigation_state(
        state_dict: dict,
        task_info: TaskInfo,
        env_id: int,
        device: torch.device
    ) -> dict:
        """生成导航任务初始状态"""
        if isinstance(task_info.goal, PointGoal):
            # 创建目标标记（可视化目标点）
            state_dict["objects"]["target_marker"] = {
                "pos": torch.tensor(task_info.goal.position, dtype=torch.float32, device=device),
                "rot": torch.tensor([1.0, 0.0, 0.0, 0.0], dtype=torch.float32, device=device),
            }
            state_dict["robots"]["franka"] = {
                "pos": torch.tensor([0.0, 0.0, 0.0], dtype=torch.float32, device=device),
                "rot": torch.tensor([1.0, 0.0, 0.0, 0.0], dtype=torch.float32, device=device),
                "joint_pos": {
                    "panda_joint1": 0.0,
                    "panda_joint2": -0.5,
                    "panda_joint3": 0.0,
                    ...
                },
            }
        return state_dict
    
    @staticmethod
    def _generate_pick_place_state(
        state_dict: dict,
        task_info: TaskInfo,
        env_id: int,
        device: torch.device
    ) -> dict:
        """生成抓取-放置任务初始状态"""
        if isinstance(task_info.goal, ObjectGoal):
            # 创建目标物体
            state_dict["objects"]["target_object"] = {
                "pos": torch.tensor(
                    [0.3 + np.random.uniform(-0.05, 0.05),  # 随机化
                    -0.2 + np.random.uniform(-0.05, 0.05),
                    0.74
                ),
                "rot": torch.tensor([1.0, 0.0, 0.0, 0.0], dtype=torch.float32, device=device),
            }
            
            # 创建目标位置标记
            if task_info.goal.target_pose is not None:
                state_dict["objects"]["target_marker"] = {
                    "pos": torch.tensor(task_info.goal.target_pose, dtype=torch.float32, device=device),
                    "rot": torch.tensor([1.0, 0.0, 0.0, 0.0], dtype=torch.float32, device=device),
                }
            
            state_dict["robots"]["franka"] = {
                "pos": torch.tensor([0.0, 0.0, 0.0], dtype=torch.float32, device=device),
                "rot": torch.tensor([1.0, 0.0, 0.0, 0.0], dtype=torch.float32, device=device),
                "joint_pos": {
                    "panda_joint1": 0.0,
                    "panda_joint2": -0.5,
                    "panda_joint3": 0.0,
                    ...
                },
            }
        return state_dict
    
    @staticmethod
    def _generate_stacking_state(
        state_dict: dict,
        task_info: TaskInfo,
        env_id: int,
        device: torch.device
    ) -> dict:
        """生成堆叠任务初始状态"""
        if isinstance(task_info.goal, SequenceGoal):
            # 创建多个物体
            base_positions = [
                [0.3, -0.2, 0.74],
                [0.4, -0.2, 0.74],
                [0.5, -0.2, 0.74],
            ]
            
            for i, step in enumerate(task_info.goal.steps):
                obj_name = step.target_object
                state_dict["objects"][obj_name] = {
                    "pos": torch.tensor(base_positions[i], dtype=torch.float32, device=device),
                    "rot": torch.tensor([1.0, 0.0, 0.0, 0.0], dtype=torch.float32, device=device),
                }
            
            state_dict["robots"]["franka"] = {
                "pos": torch.tensor([0.0, 0.0, 0.0], dtype=torch.float32, device=device),
                "rot": torch.tensor([1.0, 0.0, 0.0, 0.0], dtype=torch.float32, device=device),
                "joint_pos": {
                    "panda_joint1": 0.0,
                    "panda_joint2": -0.5,
                    "panda_joint3": 0.0,
                    ...
                },
            }
        return state_dict
    
    @staticmethod
    def _navigation_success_checker(task_info: TaskInfo):
        """导航任务成功检查器"""
        if isinstance(task_info.goal, PointGoal):
            tolerance = task_info.goal.tolerance
            def checker(states: TensorState) -> torch.Tensor:
                ee_pos = states.robots["franka"].root_state[:, 0:3]
                target_pos = states.objects["target_marker"].root_state[:, 0:3]
                distance = torch.norm(ee_pos - target_pos, dim=-1)
                return distance < tolerance
        return checker
        return lambda states: torch.zeros(states.shape[0], dtype=torch.bool)
    
    @staticmethod
    def _pick_place_success_checker(task_info: TaskInfo):
        """抓取-放置任务成功检查器"""
        if isinstance(task_info.goal, ObjectGoal):
            tolerance = 0.05
            def checker(states: TensorState) -> torch.Tensor:
                obj_pos = states.objects["target_object"].root_state[:, 0:3]
                
                if task_info.goal.target_pose is not None:
                    target_pos = task_info.goal.target_pose
                else:
                    # 检查是否有 target_marker
                    if "target_marker" in states.objects:
                        target_pos = states.objects["target_marker"].root_state[:, 0:3]
                    else:
                        return torch.zeros(states.shape[0], dtype=torch.bool)
                
                distance = torch.norm(obj_pos - target_pos, dim=-1)
                return distance < tolerance
        return checker
        return lambda states: torch.zeros(states.shape[0], dtype=torch.bool)
    
    @staticmethod
    def _stacking_success_checker(task_info: TaskInfo):
        """堆叠任务成功检查器"""
        if isinstance(task_info.goal, SequenceGoal):
            def checker(states: TensorState) -> torch.Tensor:
                # 检查每个物体的垂直位置关系
                success = torch.ones(states.shape[0], dtype=torch.bool)
                
                for i in range(len(task_info.goal.steps) - 1):
                    obj_name_i = task_info.goal.steps[i].target_object
                    obj_name_j = task_info.goal.steps[i + 1].target_object
                    
                    if obj_name_i in states.objects and obj_name_j in states.objects:
                        pos_i = states.objects[obj_name_i].root_state[:, 0:3]
                        pos_j = states.objects[obj_name_j].root_state[:, 0:3]
                        
                        # 检查物体 j 在物体 i 上方
                        height_diff = pos_j[:, 2] - pos_i[:, 2]
                        correct_height = (0.0 < height_diff) & (height_diff < 0.1)
                        success = success & correct_height
                        
                        # 检查水平对齐
                        horizontal_dist = torch.norm(pos_j[:, :2] - pos_i[:, :2], dim=-1)
                        aligned = horizontal_dist < 0.05
                        success = success & aligned
                
                return success
        return checker
        return lambda states: torch.zeros(states.shape[0], dtype=torch.bool)

## 五、统一的任务信息表示接口

### 5.1 核心接口设计

```python
from abc import ABC, abstractmethod
from typing import Dict, Any, Optional


class ITaskInfo(ABC):
    """任务信息接口
    
    所有任务信息表示都需要实现此接口
    """
    
    @abstractmethod
    def to_robotwin_format(self) -> Dict[str, str]:
        """
        转换为 RoboTwin 兼容格式
        
        Returns:
            Dict[str, str]: RoboTwin 的 info["info"] 格式
        """
        pass
    
    @abstractmethod
    def generate_initial_states(
        self,
        num_envs: int,
        device: Any,
        robot_name: str = "franka"
    ) -> list[dict]:
        """
        生成 RoboVerse 兼容的初始状态
        
        Args:
            num_envs: 环境数量
            device: 计算设备（torch.device 或 "cpu"）
            robot_name: 机器人名称
            
        Returns:
            list[dict]: 每个环境的初始状态字典
        """
        pass
    
    @abstractmethod
    def generate_success_checker(self):
        """
        生成成功检查器函数
        
        Returns:
            Callable: 接受 TensorState，返回 bool 张量
        """
        pass
    
    @abstractmethod
    def generate_reward_function(self):
        """
        生成奖励函数
        
        Returns:
            Callable: 接受 TensorState，返回 reward 张量
        """
        pass
    
    @abstractmethod
    def generate_observation_space(self) -> Optional[gym.spaces.Space]:
        """
        生成观测空间（可选）
        
        Returns:
            gym.spaces.Space 或 None
        """
        pass
    
    @abstractmethod
    def generate_action_space(self, robot_joint_limits: Dict[str, tuple]) -> Optional[gym.spaces.Space]:
        """
        生成动作空间（可选）
        
        Returns:
            gym.spaces.Space 或 None
        """
        pass
    
    @abstractmethod
    def get_task_metadata(self) -> Dict[str, Any]:
        """
        获取任务元数据
        
        Returns:
            Dict[str, Any]: 包含 difficulty, max_episode_steps 等信息
        """
        pass
```

### 5.2 具体实现示例

```python
import torch
import numpy as np
import gymnasium as gym
from metasim.types import TensorState
from task_info_definition import (
    TaskInfo, TaskType, PointGoal, ObjectGoal, SequenceGoal, ITaskInfo
)


class NavigationTaskInfo(ITaskInfo):
    """导航任务信息"""
    
    def __init__(self, task_info: TaskInfo):
        self.task_info = task_info
    
    def to_robotwin_format(self) -> Dict[str, str]:
        """转换为 RoboTwin 格式"""
        if isinstance(self.task_info.goal, PointGoal):
            pos_str = "_".join([f"{v:.3f}" for v in self.task_info.goal.position])
            return {
                "{A}": f"target_position_{pos_str}",
            }
        return {}
    
    def generate_initial_states(
        self,
        num_envs: int,
        device: Any,
        robot_name: str = "franka"
    ) -> list[dict]:
        """生成初始状态"""
        initial_states = []
        tolerance = self.task_info.goal.tolerance if isinstance(self.task_info.goal, PointGoal) else 0.05
        
        for env_id in range(num_envs):
            # 添加随机扰动
            random_offset = np.random.uniform(-0.05, 0.05, 0)
            perturbed_pos = np.array(self.task_info.goal.position) + random_offset
            
            state_dict = {
                "objects": {
                    "target_marker": {
                        "pos": torch.tensor(perturbed_pos, dtype=torch.float32, device=device),
                        "rot": torch.tensor([1.0, 0.0, 0.0, 0.0], dtype=torch.float32, device=device),
                    },
                },
                "robots": {
                    robot_name: {
                        "pos": torch.tensor([0.0, 0.0, 0.0], dtype=torch.float32, device=device),
                        "rot": torch.tensor([1.0, 0.0, 0.0, 0.0], dtype=torch.float32, device=device),
                        "joint_pos": self._get_initial_joint_pos(),
                    },
                },
                "cameras": {},
                "extras": {},
            }
            initial_states.append(state_dict)
        
        return initial_states
    
    def _get_initial_joint_pos(self) -> Dict[str, float]:
        """获取初始关节位置"""
        return {
            "panda_joint1": 0.0,
            "panda_joint2": -0.5,
            "panda_joint3": 0.0,
            "panda_joint4": -2.0,
            "panda_joint5": 0.0,
            "panda_joint6": 1.5,
            "panda_joint7": 0.785,
            "panda_finger_joint1": 0.04,
            "panda_finger_joint2": 0.04,
        }
    
    def generate_success_checker(self):
        """生成成功检查器"""
        tolerance = self.task_info.goal.tolerance if isinstance(self.task_info.goal, PointGoal) else 0.05
        def checker(states: TensorState) -> torch.Tensor:
            ee_pos = states.robots["franka"].root_state[:, 0:3]
            target_pos = states.objects["target_marker"].root_state[:, 0:3]
            distance = torch.norm(ee_pos - target_pos, dim=-1)
            return distance < tolerance
        return checker
    
    def generate_reward_function(self):
        """生成奖励函数"""
        tolerance = self.task_info.goal.tolerance if isinstance(self.task_info.goal, PointGoal) else 0.05
        def reward_func(states: TensorState) -> torch.Tensor:
            ee_pos = states.robots["franka"].root_state[:, 0:3]
            target_pos = states.objects["target_marker"].root_state[:, 0:3]
            distance = torch.norm(ee_pos - target_pos, dim=-1)
            
            # 距离奖励：越近奖励越高
            reward = -torch.tanh(distance / tolerance)  # 范围 [-1, 1]
            return reward
        return reward_func
    
    def generate_observation_space(self) -> Optional[gym.spaces.Space]:
        """生成观测空间"""
        # 观测包括：末端执行器位置、目标位置、机器人关节位置
        obs_dim = 3 + 3 + 9  # ee_pos + target_pos + joint_pos
        return gym.spaces.Box(low=-np.inf, high=np.inf, shape=(obs_dim,))
    
    def generate_action_space(self, robot_joint_limits: Dict[str, tuple]) -> Optional[gym.spaces.Space]:
        """生成动作空间"""
        # 动作空间：关节位置偏移
        return gym.spaces.Box(low=-0.1, high=0.1, shape=(9,))
    
    def get_task_metadata(self) -> Dict[str, Any]:
        """获取任务元数据"""
        return {
            "difficulty": self.task_info.difficulty,
            "max_episode_steps": self.task_info.max_episode_steps,
            "task_type": self.task_info.task_type.value,
            "task_description": self.task_info.task_description,
        }

        return {}
    
    def generate_initial_states(
        self,
        num_envs: int,
        device: Any,
        robot_name: str = "franka"
    ) -> list[dict]:
        """生成初始状态"""
        initial_states = []
        tolerance = 0.05
        
        for env_id in range(num_envs):
            # 随机化目标物体位置
            random_offset_xy = np.random.uniform(-0.1, 0.1, 2)
            random_offset_z = np.random.uniform(-0.02, 0.02, 0)
            
            obj_pos = np.array(self.task_info.goal.target_pose) + random_offset_xy
            
            state_dict = {
                "objects": {
                    "target_object": {
                        "pos": torch.tensor(obj_pos, dtype=torch.float32, device=device),
                        "rot": torch.tensor([1.0, 0.0, 0.0, 0.0], dtype=torch.float32, device=device),
                    },
                },
                "robots": {
                    robot_name: {
                        "pos": torch.tensor([0.0, 0.0, 0.0]), dtype=torch.float32, device=device),
                        "rot": torch.tensor([1.0, 0.0, 0.0, 0.0]), dtype=torch.float32, device=device),
                        "joint_pos": self._get_initial_joint_pos(),
                    },
                },
                "cameras": {},
                "extras": {},
            }
            initial_states.append(state_dict)
        
        return initial_states
    
    def generate_success_checker(self):
        """生成成功检查器"""
        def checker(states: TensorState) -> torch.Tensor:
            obj_pos = states.objects["target_object"].root_state[:, 0:3]
            target_pos = self.task_info.goal.target_pose
            distance = torch.norm(obj_pos - target_pos, dim=-1)
            return distance < 0.05
        return checker
    
    def generate_reward_function(self):
        """生成奖励函数"""
        def reward_func(states: TensorState) -> torch.Tensor:
            obj_pos = states.objects["target_object"].root_state[:, 0:3]
            ee_pos = states.robots["franka"].root_state[:, 0:3]
            target_pos = self.task_info.goal.target_pose
            
            # 抓取奖励：末端执行器接近物体
            grasp_distance = torch.norm(ee_pos - obj_pos, dim=-1)
            grasp_reward = -torch.tanh(grasp_distance / 0.1)
            
            # 放置奖励：物体接近目标位置
            place_distance = torch.norm(obj_pos - target_pos, dim=-1)
            place_reward = -torch.tanh(place_distance / 0.1) * 0.5
            
            # 综合奖励
            reward = grasp_reward + place_reward
            return reward
        return reward_func
    
    def generate_observation_space(self) -> Optional[gym.spaces.Space]:
        """生成观测空间"""
        # 观测包括：末端执行器位置、物体位置、机器人关节位置
        obs_dim = 3 + 3 + 9  # ee_pos + obj_pos + joint_pos
        return gym.spaces.Box(low=-np.inf, high=np.inf, shape=(obs_dim,))
    
    def generate_action_space(self, robot_joint_limits: Dict[str, tuple]) -> Optional[gym.spaces.Space]:
        """生成动作空间"""
        return gym.spaces.Box(low=-0.1, high=0.1, shape=(9,))
    
    def get_task_metadata(self) -> Dict[str, Any]:
        """获取任务元数据"""
        return {
            "difficulty": self.task_info.difficulty,
            "max_episode_steps": self.task_info.max_episode_steps,
            "task_type": self.task_info.task_type.value,
            "task_description": self.task_info.task_description,
        }
```

## 七、设计原则总结

### 7.1 核心设计原则

| 原则 | 说明 | 应用 |
|-------|------|------|
| **类型安全** | 使用类型枚举而非字符串 | `TaskType.NAVIGATION` vs "navigation" |
| **目标统一** | 所有任务都有 GoalInfo 统一表示 | `goal: GoalInfo` 字段 |
| **兼容性优先** | 设计适配层转换格式 | `ITaskInfo` 提供多个 `to_xxx_format()` 方法 |
| **可扩展性** | 易于添加新任务类型 | 新增 `TaskType` 和对应的 `GoalInfo` 子类 |
| **验证性** | 成功条件和奖励函数可验证 | 生成后可测试正确性 |

### 7.2 不同任务类型的关键字段

| 任务类型 | 关键信息 | 为什么需要 |
|---------|---------|----------|
| **导航** | `PointGoal: position, tolerance` | 目标位置和容差 |
| **操作** | `ObjectGoal: target_object, target_pose, functional_constraint` | 被操作物体和目标位置 |
| **堆叠** | `SequenceGoal: steps, final_state` | 操作序列和最终状态 |
| **状态** | `StateGoal: object_name, required_state` | 物体状态要求（直立、抓取等） |

### 7.3 RoboTwin vs RoboVerse 字段映射

| RoboTwin | RoboVerse | 映射关系 |
|-----------|-----------|---------|
| `{A}`, `{B}`, `{C}` | `goal.target_object` 或 `goal.steps[i].target_object` | 物体占位符 |
| `{a}`, `{b}`, `{c}` | 固定为 "left" 或 "right" | 机械臂信息（可选） |
| 无对应字段 | `goal.target_pose` | 目标位置 |
| 无对应字段 | `goal.functional_constraint` | 功能约束（on_top_of, inside, etc.） |
| 无对应字段 | `goal.tolerance` | 成功容差 |

## 八、推荐的使用模式

### 8.1 定义新任务的标准流程

1. **确定任务类型**：从 `TaskType` 枚举选择
2. **创建 GoalInfo 子类**：根据任务类型选择合适的目标表示
3. **实现 ITaskInfo 接口**：创建适配器类
4. **在两个框架中使用**：
   - RoboTwin：使用 `info["info"]` 转换
   - RoboVerse：使用 `_get_initial_states()`, `_terminated()`, `_reward()` 等方法

## 九、总结

### 9.1 核心概念

1. **任务类型枚举**：统一的任务分类系统
2. **目标信息层次**：
   - 基础：`GoalInfo`（统一接口）
   - 具体：`PointGoal`, `ObjectGoal`, `SequenceGoal` 等
3. **适配器模式**：将通用任务信息转换为框架特定格式
4. **兼容性优先**：设计能够同时支持 RoboTwin 和 RoboVerse

### 9.2 设计优势

| 特性 | 优势 |
|-------|--------|
| **类型安全** | 编译时检查，避免字符串错误 |
| **统一表示** | 所有任务使用相同的信息结构 |
| **框架无关** | 核心逻辑与具体框架解耦 |
| **易于扩展** | 添加新任务类型只需新增枚举和目标类 |
| **可验证** | 成功条件和奖励函数可独立测试 |
| **文档友好** | 类型提示清晰，易于理解 |

### 9.3 实际应用

**导航任务**：
```python
task_info = TaskInfo(
    task_type=TaskType.NAVIGATION,
    goal=PointGoal(position=[0.5, 0.0, 0.3], tolerance=0.05),
)
```

**操作任务**：
```python
task_info = TaskInfo(
    task_type=TaskType.PICK_PLACE,
    goal=ObjectGoal(
        target_object="red_block",
        target_pose=[0.5, 0.0, 0.74],

    ),

```

**堆叠任务**：
```python
task_info = TaskInfo(
    task_type=TaskType.STACKING,
    goal=SequenceGoal(steps=[
        OperationStep(operation="grasp", target_object="red_cube"),
        OperationStep(operation="place_on_top", target_object="red_cube"),
        OperationStep(operation="grasp", target_object="green_cube"),

这个统一的信息表示系统使得任务定义更加清晰、类型安全，并且能够同时支持 RoboTwin 和 RoboVerse 两种框架。
